# FlowStep Edu Simulator

Simulasi elektronik berbasis node untuk edukasi. Aplikasi ini menekankan perilaku rangkaian dan logika digital secara visual, tanpa simulasi fisika tingkat industri.

## Menjalankan di localhost

1. Pastikan berada di root repo.
2. Jalankan server statis:

```bash
python -m http.server 8000
```

3. Buka browser di:

```
http://localhost:8000/index.html
```

> Simulasi ini hanya untuk tujuan edukasi dan pemahaman konsep.
